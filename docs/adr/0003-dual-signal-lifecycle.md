# ADR-0003: 双信号生命周期（更新 + 读取）

- 日期：2026-08-11
- 状态：已接受

## 背景

纯手动失效（用户不会去管旧条目）导致 bank 逐年膨胀、搜索噪声增大、PRELOAD 预算被陈年条目挤占。纯"更新时间"衰减会误杀真正有价值的老知识（如"水位基面换算方法"3 年前写入但每季度都在查）。

## 决策

条目的冷热由**双信号**决定：

- **更新信号**：`updated_at`（内容最近修改时间）
- **读取信号**：`last_accessed`（最近被 get 读取的时间，每次读取时更新）

consolidate 规则：**长期未更新（>90 天）且长期未被读取（>60 天）**的条目 → confidence 降一级；低于阈值 → 自动转 archive（不进搜索与 PRELOAD）。被频繁读取的条目 confidence 永不因时间衰减。

## 备选方案

- 仅手动失效：无自动治理，bank 膨胀。
- 仅按更新时间衰减：误杀高频使用的老知识。
- 仅按读取频率：新写入但未读过的条目会异常沉底。

## 后果

- 记忆库冷热由实际使用塑造，而非机械时间戳。
- 成本：get 时一行 `UPDATE last_accessed`；衰减规则约 20 行 Python，挂在周 consolidate。
- 与 ADR-0001"辅助用户变强"立场一致：被读 = 有价值（复活），没人读也没人更新 = 真过时（沉底）。
